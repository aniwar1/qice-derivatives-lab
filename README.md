# Qice Derivatives Lab · 期策

期策是一个在本机运行的纸面交易研究工具。工作台有两个页面，分别查看三组策略的逐日收益、当天决策，以及 22 个品种的历史研究原文。历史模拟与盘前实际封存的判断分别标记。

`React · TypeScript`　`FastAPI · Python`　`SQLite · DuckDB`　`Codex CLI`

## 使用工作台

1. 打开 [策略总览](http://127.0.0.1:8000/#strategies)。从 2026 年 7 月 1 日起，A、B、C 各以 20 万元现金空仓起步。A、B 每笔开仓给定 10,000 元预算。C 同时给看涨和看跌各 5,000 元，两腿各按整手买入，分别扣费，合计最多 10,000 元。买入数量取可负担的整手，包含权利金、滑点和开仓手续费。每笔以预算内的最大整手数委托，现金、成交量或委托限制不足就整笔跳过。各模拟账户的在手成本上限取前一日权益的 8% 与 20,000 元中的较高值。
2. 在曲线下方查看 A 多因子方向买权、B 技术择强买权和 C 事件驱动宽跨式的入场、退出规则、当天判断及其模拟执行结果。曲线按交易日收盘权益计算，含在手仓位浮盈亏。页面分别显示日结截止日和北京时间的决策日期。
3. 打开 [品种历史分析](http://127.0.0.1:8000/#history)，按名称或代码选择品种，再按日期回看模型原文、当时的合约数据、消息来源、反证与资料缺口。

## 安装与数据

需要 Python 3.12+、Node.js 22+ 和 pnpm。运行以下命令启动服务，默认只监听本机 8000 端口。

```bash
./start.sh
```

本机数据保存在 `local-data/`。新检出保留策略说明与品种目录。要恢复已有研究工作台，需挂载或恢复受信任的本机研究数据，包括历史市场与模型归档、逐腿到期档案、向前收盘原件以及新版模拟账目。每次读回历史行情和研究回执时核对相应的来源摘要。涉及个人研究的原文仅在本机读取。

## 策略回放与日更

每个交易日使用截止时可见的技术、供需和消息资料重新判断，各组每天最多开一笔。分析结合实际月份的价格、成交、持仓与消息首次可得时间，检查利益相关方、是否已经计价及反向解释。A 核对方向情景扣费后的价值，B 核对技术优势和失效价，C 核对事前事件日程、两腿成本与到期日。

安装 Codex CLI 并登录后，在已有完整市场与来源档案的环境下运行：

```bash
export PYTHONPATH=backend:.
.venv/bin/python -m scripts.july_replay --workspace "$PWD"
.venv/bin/python -m scripts.july_settlement --workspace "$PWD"
```

回放按交易日独立处理冻结输入。A、B 保留经核验的同日万元预算信号。C 在具有事前事件与可选双腿的日期，用每腿 5,000 元的规则重新判断。缺少这些条件的日期保留有依据的观望。收盘结算按当前完整整手委托规则统一计算。历史模拟使用实际月份的开盘价代理。逐笔记录保留整手数量、费用和盈亏。没有盘前输入的前向交易日只按原规则管理旧仓，缺少必要估值时保留最后一个可核实的日结。

日更随本机服务运行。北京时间交易日 16:00 后读取日表，20:00 前分批保存下一交易日的资料，20:00 至 21:00 完成并封存新决策。关闭浏览器仍可日更，停机错过窗口会记入缺口。回放回执及前向判断写入 `local-data/july-strategy/decisions-v2/`，逐日账目写入 `local-data/july-strategy/settlement-v2.json`。每日检查也可在命令行运行：

```bash
.venv/bin/python -m scripts.rolling_update --workspace "$PWD"
```

## 增频规则的历史复核

按组比较从 7 月至 9 月的训练结果，再复核 10 月至 11 月 24 日的表现，先后保留每次研究的版本和回执。最终采用完整委托预算。B 在不同交易日再次收到独立入场信号时，可为同品种开第二笔，两笔各按自身的失效条件、期限及费用结算。A 和 C 继续采用单品种单笔持仓。用于比较的日内续挂限价、缩短持有期以及其他加仓方案均记录在实验协议中。

复核使用同一段历史的收盘权益、实际开仓数、扣费净收益与最大回撤。完整预算修正前已经看过这段日期的结果，后段属于历史分段复核。正式盘前封存的后续样本另行积累。

## 工程设计

| 问题 | 实现 | 源码入口 |
| --- | --- | --- |
| 怎样约束模型输出？ | Codex 在每轮临时工作区取证并返回结构化策略。服务复验品种、月份、证据时点、反证结论和执行权限，通过后才更新最新策略。 | [任务编排与校验](backend/app/service.py)、[输出契约](backend/schemas/codex_strategy_decision.agent.schema.json) |
| 半根日线能支持什么结论？ | 对夜盘后的部分日线，验证交易所日历、数据覆盖和采集时点。满足条件时可用于条件触发，确认突破要求完成日线。 | [日线证据校验](scripts/session_aware_bar.py)、[边界回归](tests/test_session_aware_bar.py) |
| 如何确定一笔模拟委托实际花了多少钱？ | 每日在真实开盘代理价下复核入场条件，以账户余额、整手成本和成交量计算手数。逐日权益与已实现和在手盈亏核对。 | [定额结算](scripts/july_settlement.py)、[交易账户](backend/app/agent_replay_account.py) |
| 怎样回看当时知道了什么？ | 按日期封存模型输入、判断和交易所日表摘要。历史页按品种关联原文、行情和反证，保留当时的缺口。 | [日更](backend/app/july_daily.py)、[品种记录](backend/app/product_history.py) |
