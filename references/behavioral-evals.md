# 行为回归

评测观察实际输出：相同输入是否走对路径，反证能否改变结论，缺证有没有被说成成交或盈利。不以是否命中某串文字评分。以下按改动范围选用，不要求每次市场分析执行整套评测。

| 请求与对照 | 观察点 |
|---|---|
| 默认“更新”；明确只要候选；四个机会均合格；所有候选均有关键缺口 | 默认宽筛并逐个验证，不限机会数、不查账户、不复核旧仓；仅在用户要求时展示未核验观察项。见[合成准入案例](evals/opportunity-admission-cases.json)。 |
| 有方向但 IV 昂贵；低 IV 却无近期启动；成熟压缩但尚未突破；重大反向供需证据到达 | 比较提前布局、突破确认和等待；不能因某一项很强忽略其余条件。新的关键反证应改变判断或撤掉候选，不在 `wait` 后暗示单边交易。 |
| 只有系列 IV、理论价或期货 HV；五根日 K 算收益；方向对但降波；期权快照已重估 | 不虚构历史分位、到价概率或升波；窗口按收益条数，区分换月价差、理论情景及可执行价格，重新评估过时的候选。 |
| 标的月份错配、盘口陈旧/倒挂、到期早于兑现窗口；期权持仓约束与新开仓准入冲突 | 阻断不具备条件的开仓。已持仓按原假设和执行失效复核，不能因 IV 已不低或未设最大亏损自动退出。 |
| 权利金下跌、用户追问等回本；同样的浮亏下分别给出驱动强化、失效、取证不足、原止损已触发 | 先做基本面、资金、消息与技术综合；合理区别持有、平仓、未完成复核及原止损优先。 |
| 库存有不同日期或样本、会员当日榜为空、日 K 缺当日但有旧结构与最新报价 | 保留有效证据并说明窗口；不能拼接两种库存、用旧榜填今天或把收盘报价包装成完整日 K。用[证据口径案例](evals/evidence-provenance-cases.json)检查。 |
| 夜盘收盘检查点前后、无夜盘品种、缺交易日历、partial 与 completed 被互换 | 仅按品种真实夜盘结束时点和覆盖放行 partial；不重算确认枢轴，不用 partial 或盘中报价声称完成日线突破。 |
| 成交意图未预登记；只存在行情复盘、未平仓、假设交易或模拟结果；明确要求流程修复 | 不向真实结果账本追加，不用单例升级交易规则；已证实的流程问题可以先修复。协议要求的模拟分母、版本与失败样本不能删。 |
| 复盘起爆/二次启动；刺穿后收平；下一分钟收过固定边界；同期出现假突破、迟发消息或缺分钟行情 | 用[历史行情合成案例](evals/historical-replay-cases.json)检查能否定位信号及下一可检查时段，保留失败与粒度限制，不回填成交或发布现在的买入建议。 |

给独立评测者请求、当前 Skill 与最少必要输入，不预告期望答案。使用隔离临时目录，不写正式账本、不下单。先复算时间、身份、数量和契约，再核查因果、可证伪性和最终措辞。最多作一次有依据的修订；重大问题仍未解决即记录未通过。记录结果与验证边界，不将行为评测称作策略盈利回测。
