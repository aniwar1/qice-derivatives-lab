# 会员持仓资金判读

仅在解释 Top20 或重点会员时加载。交易所披露的是会员席位汇总，混有自营、客户、套保和套利；“主力资金”只能表示会员集中持仓，不能等同于单一机构观点。它是三面因果链中的持仓行为证据，不是投票项或机械交易信号。

## 数据边界

- 固定核查 Top20，以及五大内资中信期货、永安期货、国泰君安、银河期货、东证期货和三大外资乾坤期货、摩根大通、瑞银期货。榜外不等于持仓为零，名称映射须保留原始席位名。
- 三日窗口截止最近完成交易日且日期连续；跳过工作日必须有交易所休市来源。末日合约、收盘、成交量和总持仓须与 `latest_completed_bar` 一致。
- 页面行情日期和榜单数据日期分别核对；缺末日榜时明确三日窗口未完成，不能用更早一天补齐或用0代表抓取空表。日期、样本与回退口径统一见 [事实级时点与样本口径](evidence-contract.md#事实级时点与样本口径)。
- `available` 的多空持仓不得同时补成 0。只见一侧时标记 `partial/mixed`，只填写 `observed_metrics` 中的字段，不得推断另一侧或声称已确定净方向。
- 对可观测的具名席位，首日相对窗口前一完成日的同侧持仓，此后相对相邻交易日同席位同侧持仓核对变化。Top20 因入榜名单变化，使用榜单披露的组成项及增减值，不能差分两日汇总持仓。
- 缺失是 `unobservable`，证据冲突或接近噪声是 `mixed`；两者不能互换。重点席位与 Top20 属同一证据簇，不重复计票。

## 组合与归一化

分别保留多单变化 `ΔL`、空单变化 `ΔS`，并可描述 `ΔNet = ΔL - ΔS`。它只叫“会员持仓不平衡变化”，不能叫全市场净仓。

- `ΔL > 0, ΔS < 0` 是加多减空；`ΔL < 0, ΔS > 0` 是减多加空，但仍须解释价格、总持仓与背后驱动。
- 两边同增时，`ΔNet` 只描述哪一侧增加更快；同月价格和总持仓可帮助比较竞争解释，不能据净额或总持仓确认主动方。
- **两边同减时，不得凭 `ΔNet` 的正负直接判多空。** 先标记为去杠杆或席位迁移候选；相对减仓速度只能描述拥挤度释放，不能成为新开仓方向依据。
- 每日同时给出 `ΔL / OI_previous`、`ΔS / OI_previous` 与 `ΔNet / OI_previous`；`OI_previous` 必须是同一分析合约上一完成交易日的全市场总持仓。缺少该分母就不做跨日或跨品种强弱比较。
- Top20 另列 `top20_long / OI` 与 `top20_short / OI` 覆盖率；覆盖率变化显著时，先考虑榜单覆盖变化，不能把名次迁移误写成资金流入流出。

## 与价格、总持仓联判

- 价格变动且总持仓增加，说明未平仓合约增加，每份合约都有多空两方。总持仓减少说明未平仓合约收缩。价格上涨伴随减仓与空头回补相容，但不能排除多头退出、移仓或其他交易，也不能据总量还原资金身份。
- 比较时写明起止时点和是否包含首根 K 线。两个分钟收盘的持仓差只涵盖两端之间的变化；盘后榜单只能用于其公布后的判断。历史驱动核查见[行情复盘](historical-replay.md)。
- 将会员、合约总持仓、价格和受影响月份一起比较。若观察不一致，检验套保、移仓、跨期套利和名单变化等解释；没有证据辨别时保留不确定。
